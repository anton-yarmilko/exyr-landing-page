- `public/assets/exyr-phone-pair.png`: focused crop from the public Exyr author case-study image linked in the README. Used to preserve the supplied mobile-device artwork rather than recreate it in CSS.
- `public/assets/exyr-orbit-rings.png`: generated with built-in ImageGen for the measured hero slot; pale concentric rings on a solid background, with no text, logos, UI, shadows, glow, or gradients.
- `public/assets/exyr-network-map.png`: generated with built-in ImageGen for the map feature slot; restrained pale connection-map artwork on a solid background, with no text, logos, UI, or gradients.
- `public/assets/exyr-contact-rings.png`: generated with built-in ImageGen for the contact CTA slot; continuous faint hairline rings on solid white, with no text, logos, UI, shadows, glow, or gradients.
- Connector and customer marks: official paths from `simple-icons`.
- Interface icons: `@phosphor-icons/react`.
- Typeface: locally bundled Inter variable font through `@fontsource-variable/inter`.
