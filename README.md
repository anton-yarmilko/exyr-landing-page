# Exyr landing page

Production-ready responsive implementation of the public Exyr landing-page concept.

## Development

```bash
npm install
npm run dev
```

## Verification

```bash
npm test
npm run build
npm audit --omit=dev
```

The build emits both a Vite client bundle and the Sites worker packaging files.
